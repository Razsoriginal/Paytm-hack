# Taste

## Workflow

- Prefers deploying by connecting the repo directly in the host's dashboard (e.g. Vercel import screen with Root Directory + framework preset), not by installing and running CLI tooling — "direct connect, no need other command". Confidence: 0.6

## Communication

- When producing text the user will copy and paste elsewhere (e.g. into a form), avoid markdown bold markers (`**`) — they paste through as literal characters. Give plain text instead. Confidence: 0.6
